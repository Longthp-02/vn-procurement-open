# AI Author Review Package

Prepare a review package for the change you just made. Do not modify code while preparing it.

Include:
1. Original requirement summary (and any clarifications)
2. Changed files in logical reading order, one line each on why
3. Risk areas (what could break, what you were unsure about)
4. Proof it works: exact commands run and their output (tests, typecheck, lint, build); say what was not run
5. The full diff

Do not hide weaknesses, shortcuts or skipped checks.
