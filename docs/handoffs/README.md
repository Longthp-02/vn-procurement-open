# Handoffs

Write a handoff note whenever a pipeline change affects what the web reads (the JSON files under `web/public/data/` or `docs/data-contract.md`).

- One file per change: `YYYY-MM-DD-<short-topic>.md`, based on `_template.md`.
- "Endpoints" here means generated JSON files (e.g. `tender/<id>.json`).
- Link the note from the PR description.
