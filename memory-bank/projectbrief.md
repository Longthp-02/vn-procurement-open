# Project Brief

## Purpose
Make Vietnam's published public procurement data readable and verifiable for citizens, journalists and researchers, for free.

## MVP Scope
Ho Chi Minh City tenders: crawler, normalization, search, tender/contractor/buyer/topic pages, neutral indicators, open downloads. Sample data until the crawler works.

## Non-goals
Risk labels, personal data, complaint system, accounts, monetization, budget data, public API (see `spec.md`).

## Success Definition
- Site live with real HCMC data refreshed daily
- Every number traceable to its source document
- Dataset downloaded and reused by at least one journalist or researcher (TODO: verify target)
