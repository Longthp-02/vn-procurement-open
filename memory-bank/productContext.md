# Product Context

## Why It Exists
Procurement data is public but scattered and hard to compare. Commercial tools serve bidders; nobody serves the public. The owner also builds it in public for personal branding (LinkedIn posts per milestone).

## Target Users
Citizens, journalists, researchers (TODO: verify priority).

## Main Workflows
1. Search a tender by keyword, entity or tax code → read its numbers and sources
2. Open a contractor or procuring entity → see its history and concentration
3. Compare provinces → see indicators side by side
4. Browse a topic (schools, medical equipment, roads)
5. Download the dataset

## Business / Domain Goals
Neutral transparency, reproducibility, zero running cost.

## Domain Rules
- Neutral wording only; no risk labels (owner decision, 2026-10-03)
- Organizations only, no personal data
- Every number has source + collection date + methodology
- Indicator definitions: proposed, TODO: verify
